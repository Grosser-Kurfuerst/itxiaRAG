# 第二阶段需求

状态：需求，未实现。2026-10-10 依据[总体需求](../requirements.md)第 5 节（P1）和[召回效果评测](../phase1/yuque-ingestion/retrieval-evaluation.md)第 9 节整理。

## 1. 背景与目标

第一阶段的 P0 需求 F-01～F-09 已全部实现。正式库现有两类资料：

- 78 篇笔吧评测；
- 74 篇语雀文档，含教程 28、知识 15、工具 31。

合计约 1400 个子块。查询集 v4 共 142 条，在语料 v3 上的评测结果如下：

- 全部有答案查询：混合 Hit@5 0.90、MRR@10 0.816。
- 知识类（K）Hit@5 1.00，教程类（T）Hit@5 1.00，基础查询稳定。
- 按条件找机器（D 类）：Hit@5 0.42、P@5 0.237。检索不理解预算、重量、接口等条件，知识文档还会挤进推荐类结果。
- 用途类提问（U 类）：Hit@1 0.67，存在三个问题：用词与原文对不上、复合词切得过粗、同类工具条目互相竞争。
- 维修参考是总体需求的三个使用场景之一，但语料里只有零散教程。语雀中的排障指南（10 篇）和单案例记录（12 篇）还没有接入。

第二阶段有两条主线：

1. **检索质量**：以评测为依据改进召回和排序，重点是推荐类查询和用途类查询。
2. **维修类内容**：接入语雀排障指南和单案例记录，补上维修参考场景的语料与评测。

两条主线互不依赖，可以并行。维修类内容导入后，检索改进需要在新语料上重新评测。

## 2. 范围

第二阶段从总体需求 P1 中选取以下各项：

| P1 项 | 本阶段内容 | 不在本阶段 |
| --- | --- | --- |
| 检索质量 | 评测补齐、融合参数、分词、同义扩展、价格日期标注 | pgvector、持久化倒排索引（见第 5 节） |
| 查询预处理 | 选购条件解析、同义扩展、型号与年份提取，均基于规则 | 意图分类模型、大模型改写 |
| 场景策略 | 购机和维修的静态来源偏好 | 子块级 knowledge_type、按主题 metadata 过滤 |
| 类型化处理扩展 | 排障指南、单案例记录两条流水线，可选修复选购指南分段 | 其他新格式 |
| 可选重排 | 本地重排模型，按评测收益决定是否启用 | 外部重排服务 |
| 来源连接器 | 语雀排障、案例类别接入现有语雀导入 | 语雀非公开库、维修登记系统 |

检索改进的问题依据、改动位置与采纳条件见[召回改进方案](retrieval-improvement-plan.md)。本文只列需求和验收，不重复方案细节。

## 3. 功能需求

“必做”指本阶段必须完成。“按数据”指先实现并评测，达到采纳条件才默认启用，否则记录结论后不启用。

## 4. 非功能要求

- **单变量评测**：检索改进每次只改一个变量，单独评测、单独提交。报告记录参数、语料版本和查询集版本，结果写回评测文档第 9 节。原有类别的统一底线是 A～F 类 Hit@5、MRR@10 下降不超过约 0.02。
- **不外发原文**：查询解析、同义扩展和重排都在本地完成，不调用外部大模型，不把原文发给外部服务。
- **权限不变**：查询预处理和后处理只能调整排序或缩小结果，不能扩大权限范围。
- **依赖方向**：解析规则、来源偏好和重排都作为召回后处理或查询预处理的步骤接入组合根，不改查询主循环，也不直接拼接模型厂商的请求。
- **延迟**：当前约 1400 个子块，单次查询约 1.2～1.7 秒。本阶段不设硬性指标；每项改进记录查询耗时，新增模型调用的项必须实测。
- **测试与文档**：新增流水线必须通过统一 DTO 合约测试；新增后处理步骤要验证候选结构和失败行为。代码修改要同步预处理、首期技术设计和语雀导入的相关文档。

## 5. 不进入第二阶段

| 项 | 暂不做的原因 | 重新考虑的条件 |
| --- | --- | --- |
| pgvector、持久化倒排索引、数据库 BM25 | 当前规模下耗时可接受 | 子块数达到约 5000，或有明确的延迟目标 |
| 语雀非公开库（timdoc、handbook 等） | 需要团队 Token 和授权 | 维护者提供 Token 并确认可用范围 |
| 维修登记系统连接器 | 没有可读的登记系统，脱敏规则未定；手工整理成标准 JSON 的方式仍然可用 | 登记系统可读，且脱敏流程确定 |
| 意图分类模型、大模型改写查询 | 规则已能覆盖选购条件和维修词 | 规则漏判比例经评测证明过高 |
| 为教程或工具条目生成问题式摘要 | 需要把原文发给外部模型 | 有获准的本地模型且评测证明有效 |
| 分数门槛识别无答案 | 评测已证明不可行 | 无 |
| 知识页、Spec、图谱 | 没有证据表明能改善具体检索问题 | 出现结构化知识才能解决的失败样本 |
| P2 自进化 | 失败样本还在积累 | 第二阶段结束后评估 |
