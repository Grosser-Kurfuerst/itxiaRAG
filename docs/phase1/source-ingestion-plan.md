# 语雀与微信公众号来源接入方案

> 历史调研与后续选项：本文的 Worker、解析、治理及部署建议不代表当前实现要求。当前范围以[最小混合检索技术设计](phase1-technical-design.md)为准；具体来源预处理暂未实现，仅保留插件接口。

版本：v0.4（简化为首期输入边界与后续接入入口）  
设计更新：2026-10-01；既有调研日期：2026-09-28

相关设计：[首期技术设计](./phase1-technical-design.md) · [首期需求与技术选型](./phase1-requirements-and-selection.md)

首期由维护者提供获准的 TXT／Markdown 和来源参数，通过管理命令或维护 API 导入。本文只定义资料准备与系统交接边界；语雀、笔吧评测室的专用读取、格式转换和解析算法后续按真实样本设计，不作为当前通用管线的实现前提。

## 1. 来源与授权边界

| 来源 | 首期输入路径 | 后续接入条件 |
| --- | --- | --- |
| 社团语雀 | 获授权成员导出或整理为 TXT／Markdown，确认内部／公开范围 | 团队 Token 或稳定导出格式可用后，再设计只读适配器 |
| 笔吧评测室微信文章 | 使用获准文章或内容方提供的文件，整理为 TXT／Markdown，核验账号、日期和出处 | 获得适用的公众号后台授权后评估官方 API；否则按获准单篇资料导入 |
| 社团维修记录 | 成员先脱敏，区分现象、检查、措施、结果及未确认项 | 继续复用人工输入或今后登记的来源适配器 |

可以阅读原站不代表允许复制、公开或发送给外部模型；各项范围由维护者确认。授权未确认时不导入正文，公开搜索只用于发现候选。原站公开状态不能自动决定本系统 visibility，个人信息与凭据不进入导入资料或日志。

## 2. 资料准备与提交

维护者提供正文文件及来源参数即可；命令参数或小型 JSON 文件与 API 使用同一校验器。首期不要求 SourcePackage 整包、原始 HTML／Lake、图片目录或长期原文归档。

| 输入信息 | 准备要求 |
| --- | --- |
| 来源身份与阅读链接 | source_type、canonical_locator、source_url；保留真实渠道，上传方式不改变来源类型 |
| 标题、作者与日期 | 使用原始资料信息，未知按公共契约留空；不能用导入时间冒充发布日期／价格日期 |
| 授权与可见性 | 维护者确认使用范围、public／internal 及外部模型许可 |
| 正文与内容类型 | UTF-8 TXT／Markdown、document_schema／schema_version；只提交已启用 Schema |
| 可选输入 | source_metadata 保存渠道定位；domain_metadata 仅补充有依据的信息，缺省为 `{}` |

字段类型、枚举、内容 hash 和错误响应统一见[技术设计第 4、6 节](./phase1-technical-design.md)，本文不重复定义。

稳定身份与阅读链接分别保存。语雀可用经核验的 host／repo ID／doc ID，微信可用账号／文章 ID／条目序号；ID 不可得时保留已验证链接或人工稳定标识。签名 URL 不随意删参数，不凭 ID 拼接并宣称得到永久可用链接。

整理正文时保留标题层级、表格的表头和单位、型号／配置、局部测试条件、日期及原有警告，并能定位到本次输入。图片中的关键参数首期人工补为文字／表格并注明图号和补录依据；缺图影响理解时先补录或提交明确标注范围的自足摘录，不能当完整正文发布。未知参数不要猜测补齐。

笔吧评测仍按同一文章“一台笔记本一个完整父段”，子块只负责召回；其他类型按自己的 Schema 确定父段边界。公共父子、定位和长度约束见[技术设计第 4.2.4 节](./phase1-technical-design.md#424-父上下文构建与检索子块)，具体平台解析方法暂不展开。

## 3. 导入、更新与重建

```text
准备获准正文与来源参数 → 命令／API 提交
→ 固定本次 import_job 输入与配置 → 解析并生成父段／子块
→ 字段、定位、父子与索引校验 → 自动放行或异常复核
→ 切换 current_build_id → 子块召回、完整父段返回
```

这条链路统一复用 M2/M3/M4，不增加来源专属发布流程。新处理器先验收代表样本，同配置正常任务自动发布；硬错误失败，待复核候选不对外查询。具体注册、重试和事务规则见[技术设计第 2.6、5 节](./phase1-technical-design.md)。

- 普通内容更新重新取得最新获准正文或人工上传，生成候选并校验；成功才原子替换，失败保留当前构建。
- 同一失败任务重试使用已经固定的输入和配置；重新抓取或修订正文须新建任务。
- 模型／索引升级按技术设计第 4.4 节停机维护，完成全部候选、校验和切换后恢复服务。
- 重建不依赖 source_version 或长期文件归档。外部源不可恢复时报错，由维护者补充输入；人工补录资料须保留当前整理文本或在重建时重新提供。
- 停用、撤回和限权立即阻断查询与引用；抓取失败不等于原文删除，不能用登录页／验证码页替换已发布正文。

私有文件卷仅在有附件／大文件需求时启用，不承担在线检索。全文仍保留时可经授权读取，已清理时回源取得的是最新文本，不能冒充旧构建原文；当前引用以父子产物保存的摘录与位置为准。

## 4. 样本验收与后续设计

首期用少量获准语雀、笔吧和维修样本验证来源、日期、权限及定位；包含表格、图片补录、多机／多配置和内部资料。检查重复导入、内容更新、正常自动放行、异常复核、失败保旧及撤回；通过质量报告核对型号、条件、正文覆盖和父子关系。完整验收统一见[技术设计第 8 节](./phase1-technical-design.md)，能读取页面不等于导入质量通过。

后续来源适配器只需输出上述正文与来源参数，进入同一候选构建流程。届时再按样本设计 API 分页／限流、HTML／Lake 转换、图片与未解析节点、稳定 ID、更新／删除判定和失败恢复。先验证单篇与离线文件，再接定时同步；SourcePackage 可作为传输格式选择，不新增强制存储层。

## 5. 既有调研线索

以下为 2026-09-28 的调研记录，本次简化未重新测试外部平台：

- 已登录会话读到社团语雀目录和一篇正文；通用网页提取有截图及标题层级缺失。尚未使用社团 Token 或执行整库导出，API／导出格式与权限仍待验证。
- 读到一篇笔吧历史评测，页面有配置、价格和测试条件；图片存在 src 占位、data-src 为真实地址的情况。没有验证批量读取、图片下载或 OCR。
- 官方公众号发布接口依赖对应账号凭证与权限，不能用于无授权读取第三方公众号全量文章。既有调研中 wechat-article-exporter 已声明上游关闭、停止维护，不列为生产依赖。
