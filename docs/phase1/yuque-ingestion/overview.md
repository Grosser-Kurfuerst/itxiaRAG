# 语雀文档导入方案

本目录维护南京大学 IT 侠语雀文档（团队 `itxia`）的分批导入方案。语雀只是来源平台：文档经过平台读取、类别判定和格式规范化后，仍提交给现有原文预处理与统一导入链。通用的解析、分段、预算和原文 API 契约以[文档预处理](../preprocessing.md)为准，资料授权与提交方式以[来源接入说明](../source-ingestion-plan.md)为准。

## 当前状态

**阶段 1～3 已实现；阶段 4 的读取已改为匿名读取公开网页并实测，教程检索与人工抽查待补；阶段 5、6 已实现，第一批 74 篇已导入开发环境并完成检索抽查。** 原文 API 已支持 `text/x-yuque-markdown`、`tutorial@1`、`knowledge@1` 与 `tool_card@1`，教程可按章节自适应划分父段，附风险提示、时效提示与目录检索前缀，也可继续搭配原有三种 schema 使用。`import_yuque` 已支持公开网页／快照读取、清单分类、离线试运行与批量导入；`--save-snapshot` 保存清单内全部已分类正文，包括未接入类别，不受 `--only` 导入范围限制。知识类长表格按行组拆成子块，每组检索文本带表头；工具条目一个工具一个父段，父段带工具名、用途与分类，文档警告带最后更新日期。本目录描述第一批三类文档的需求与技术方案，实现按[分阶段实现方案](implementation-phases.md)推进；每完成一个阶段，按该阶段列出的范围同步文档，并在下表更新状态。

试运行成功状态为 `preprocessed`，不调用 Embedding 或数据库保存；无账号时直接运行注册预处理器，提供账号时执行与 API 相同的来源权限校验。`--save-snapshot --dry-run` 仍会保存快照文件。正式导入复用原文请求 Serializer、DTO 转换，依次调用 `preprocess_raw` 与 `import_processed`。操作命令见 [README](../../../README.md#语雀导入)。

## 数据来源

- 快照时间：2026-10-08。团队空间共 11 个知识库，其中 8 个公开；匿名可读 6 个，共 122 篇公开文档、约 21 万字。正文另链接 timdoc、handbook、xqa 等非公开库，需要成员 Token 才能读取，不在本次分析范围。
- 读取方式：语雀网页的未公开接口（知识库列表、目录、文档列表）和单篇 Markdown 导出。导入命令现在使用同一组网页接口，见[技术方案第 7 节](technical-design.md#7-导入工具)。
- 快照和分析脚本放在本机临时目录，不提交到仓库。文中的统计数字只描述该快照，不作为验收标准。
